1

Straight Splice

Systems
ET3/ET5NEMACT
Hardware
2× splice plates + SBH/CNH bolts
Use In Data Centre
Every straight run longer than one tray length (3m ET / 6m NEMA). Main corridors, within data halls, risers.
Rule
Splice sits on OUTSIDE of rails. Smooth bolt heads face INSIDE (won't damage cables). Gap 3-5mm between tray ends.
2

90° Horizontal Bend (NEMA — Factory Fitting)

Systems
NEMACT
Hardware
1× bend fitting + 4× splice plates (NEMA) or taper-fit (CT)
Radius
NEMA: 300/450mm standard. CT: 150mm fixed.
Critical Rule
Bend is a SEPARATE piece. THREE components: Straight → [splice] → Bend → [splice] → Straight. Never model as one continuous piece.
3

90° Horizontal Bend (ET5 — Field Fabricated)

Systems
ET3/ET5
Hardware
1× Radius Plate (RP) + 2-4× splice plates at rail cuts
Key Difference from Joint 2
NO separate bend piece. Tray base is CONTINUOUS (one piece, bent in place). Only the RAILS are cut. RP supports the curve from underneath. Any angle possible.
Use In Data Centre
All ET system bends. Custom angles for non-standard geometry. Variable radius (set by RP position from cut).
4

Tee Junction (T-intersection)

Systems
ET3/ET5NEMACT
Hardware
ET: 2× TX brackets. NEMA: tee fitting + splices. CT: CTT + WIZZ.
Construction (ET)
Cut main tray rail to create opening. Bend cut flap DOWN. Insert branch. TX bracket bolts across joint on both sides of cut. Main base remains unbroken.
Use In Data Centre
Main corridor feeding branches to each rack row. Sub-main tray splitting to PDU feeds. BMS tray branching to zones.
5

Cross Junction (4-way)

Systems
ET3/ET5NEMACT
Hardware
ET: 4× TX brackets. NEMA: cross fitting + 8× splices. CT: CTC + WIZZ.
Use In Data Centre
Where N-S and E-W cable routes cross. Central distribution nodes above MSB. Major corridor intersections.
6

External Riser (Up)

Systems
ET3/ET5NEMACT
Hardware
ET: 2× Riser Links (RL). NEMA: external riser fitting + splices. CT: CTER.
Rule
Cable on OUTSIDE of bend (tension). Support within 300mm of direction change. Riser link on EACH side rail.
Use In Data Centre
Basement to ground floor transition. Under-floor to overhead. Transformer pit up to cable corridor.
7

Internal Riser (Down)

Systems
ET3/ET5NEMACT
Hardware
2× RL + hold-down clips (HD) every 1.5m on vertical
Key Difference from Joint 6
Cable on INSIDE of bend (compression). Gravity pulls cable away from tray on vertical section — hold-down clips MANDATORY.
Use In Data Centre
Overhead tray dropping to switchboard. Drops to rack PDUs. Tray entering under-floor void.
8

CT Taper-Fit (Telescope Connection)

Systems
CT only
Hardware
M6×10 screws + M6 flanged nuts (WIZZ). Min 2 per joint.
Dimensions
Overlap: 30-50mm. Side wall: 20mm. Fixed 150mm radius.
Key Feature
NO splice plates needed. Taper-folded edges ARE the connection — one end folds IN, other folds OUT. They telescope together. Screws fix through perforated base.
9

Straight Reducer (Width Transition)

Systems
NEMAET (field-cut)
Hardware
1× reducer fitting + 4× splice plates (2 per end)
Use In Data Centre
Where cable count reduces after branches peel off. Main corridor (900mm) tapering as it passes each row. Approaching switchboard entry.
10

Offset / S-Bend (Lateral Shift)

Systems
ET3/ET5NEMA
Hardware
ET: 2× RP + 4× splices. NEMA: 2× bend fittings + 6× splices.
Use In Data Centre
Routing around columns, dodging ductwork, shifting tray alignment between rooms, accommodating structural beams. Entry and exit are PARALLEL but laterally offset.

Prohibited Connections (What NOT to Model)

WRONG
WHY IT FAILS
CORRECT METHOD
Butt two tray ends together (no splice)
No structural connection. Falls apart. No earth continuity.
Splice plates on outside of both rails.
Merge bend directly into straight (shared edge)
Two raised side rails cannot physically mate edge-to-edge.
ET: cut+RP (continuous base). NEMA: splice between separate pieces.
CT fitting with non-150mm radius
ALL CT fittings manufactured at fixed 150mm. Cannot modify.
Use ET/NEMA system if larger radius needed.
Mix CT with ET3/ET5 in same run
Different profiles (20mm vs 50/85mm sides). Incompatible interfaces.
One system per run. End plate at system transitions.
Bend tighter than cable minimum radius
Insulation damage, reduced capacity, potential fault.
Fitting radius must be ≥ largest cable's min bend radius.
No support within 300mm of direction change
AS/NZS 3000 cl. 3.9.5 non-compliant. Joint failure risk.
Support bracket within 300mm of EVERY bend, tee, riser, termination.
