AS/NZS 3008 checks

What it does

Sizes the cable for a connection between two points in the power network — a source (switchboard, PDU, transformer) and a load (PDU, rack, motor, CDU). Runs the four AS/NZS 3008 checks in order and returns the smallest catalogue size that passes all of them, with a full audit trail.

#CheckBasis
1Current-carrying capacity Catalogue rating × derating ≥ design current
2Voltage drop AS/NZS 3000:2018 clause 3.6.2 — 5% / 7%
3Short-circuit withstand Adiabatic I²t = K²S², K computed
4Earth fault loop impedance Only when a protective device is declared

Ratings come from ../cables/cable_catalog.json (Nexans Australia). No AS/NZS 3008 rating table is reproduced — the methodology is implemented and the manufacturer catalogue supplies the ratings.

Headline findings

The K constant is computed, not looked up

AS/NZS 3008 publishes K in a table, but it is a closed-form result of the adiabatic heat balance. Implementing it directly handles the non-tabulated temperature pairs that a computed operating temperature produces. Validated against six published values, worst error 0.59%.

Harmonics can make the neutral larger than the active

AS/NZS 3000:2018 clause 3.5.2: a harmonic load ≥40% of the total load on any phase is “substantial”, and third-order harmonics are added to the out-of-balance current. They are additive in the neutral, so it can need more copper than the actives. IT loads, VSDs and switch-mode supplies routinely exceed the threshold.

Linear load, 250 kW PDU feeder     Active 300 mm2   Neutral 300 mm2
55% harmonic content, same load    Active 300 mm2   Neutral 630 mm2  (567 A)

Voltage drop is a cumulative budget, not per segment

Clause 3.6.2 limits the drop from the point of supply to any point, and clause C4.1 confirms percentages for consumer mains, submains and final subcircuits are “added together”. A chain of individually compliant segments can still breach the limit, so voltage_drop_budget() checks a whole path.

Two data errors caught by cross-checking

Skin effect. Scaling DC resistance by temperature alone understated AC resistance by 10.7% at 630 mm² — the unsafe direction for voltage drop. An AC/DC ratio derived from the catalogue closes it to 0.05%.

Reactance. Back-solving AS/NZS 3000:2018 Table C8 gives 0.105–0.114 Ω/km for multicore over 16–95 mm², about 33% above the 0.08 Ω/km previously assumed. The nominal is now split by construction. Every catalogue cable is single-core, so selections are unchanged.

Citation corrected: there is no “Table 5.1” for earth sizes

Secondary sources cite “AS/NZS 3000 Table 5.1”, which is wrong twice over. Clause 3.5.3 states the earthing conductor is sized per clause 5.3.3. The label also collides with AS/NZS 3008.1.1:2025 Table 5.1, which is the K constant table.

Driven end-to-end, the engine returns 3×500 mm² where the paper concludes 3×630 — the paper steps 2×400 straight to 3×630 and never evaluates 500, which passes at 3.15% against a 3.2% limit. A cheaper valid answer, not an error.
